# ECON1626 Labour Policy Proposal

This repository contains my Assessment 2 policy proposal for ECON1626: Economics of Artificial Intelligence.

## Project Overview

This project presents a policy proposal advising the Department of Employment and Workplace Relations on how Australia should respond to the labour-market impacts of generative AI.

The proposal focuses on:

- AI-driven task change
- employment and wage impacts
- industry structure and productivity
- distributional risks
- policy options for worker adjustment and firm adoption
